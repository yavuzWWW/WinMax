# Support

## Before opening an issue

1. Confirm `/Applications/WinMax.app` is enabled in **System Settings → Privacy & Security → Accessibility**.
2. Make sure you are not launching an old copy from a mounted DMG.
3. Reproduce the problem with the latest release.
4. Open WinMax and use **Copy diagnostics**.
5. Check [Troubleshooting](docs/TROUBLESHOOTING.md), especially the WinMax-only TCC reset if macOS shows permission as enabled while WinMax still sees it as denied.

## Bug reports

Use the GitHub bug-report form and include:

- macOS version
- Mac architecture (Apple Silicon or Intel)
- affected application
- affected WinMax feature: maximize, Aero Snap, Menu Vault, startup, or onboarding
- exact action that failed
- WinMax diagnostics

For Aero Snap, include the display arrangement and target edge/corner when relevant. For Menu Vault, include the owning app but avoid pasting sensitive status-item content unless it is required to reproduce the bug.

Do not include sensitive document names or private data. WinMax deliberately avoids recording window titles, document contents, Menu Vault labels and keystroke text in its logs.
