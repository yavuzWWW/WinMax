# Support

## Before opening an issue

1. Confirm WinMax is enabled in **System Settings → Privacy & Security → Accessibility**.
2. Quit and reopen WinMax after changing Accessibility permission.
3. Reproduce the problem with the latest release.
4. Open WinMax and use **Copy diagnostics**.

## Bug reports

Use the GitHub bug-report form and include:

- macOS version
- Mac architecture (Apple Silicon or Intel)
- affected application
- exact action that failed
- WinMax diagnostics

Do not include sensitive document names or private data. WinMax deliberately avoids recording window titles in its logs.
