# Community Conduct

WinMax is a technical open-source project. Discussions, issues and pull requests should remain focused, constructive and respectful.

Do not harass contributors, publish private information, intentionally disrupt project spaces, or use issue trackers for spam. Security reports that could put users at risk should be handled privately as described in `SECURITY.md`.

Maintainers may edit, hide or remove content that materially disrupts the project and may restrict participation when necessary to protect contributors or users.
